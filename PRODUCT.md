# Product

## Register

brand

## Users
Recruiters, engineering managers, technical leads, and potential collaborators evaluating Abdul Raheem's backend software engineering background, Spring Boot microservice capabilities, and portfolio projects.

## Product Purpose
Personal software engineer portfolio website showcasing backend expertise, microservices architecture, education (MTech CS at UVCE with 8.58 CGPA), professional experience (Techmile / Insuremile, Ignite3i), research publications, certifications, and featured projects with clean accessibility and responsive performance.

## Brand Personality
Minimalist, technical, restrained, confident, precise.

## Anti-references
Flashy neon/RGB gradients, glassmorphism overload, generic SaaS card grids, decorative side-stripe borders, tiny uppercase tracked eyebrows on every section.

## Design Principles
1. Technical Restraint: Let backend systems craftsmanship, microservices experience, and published research speak over visual clutter or superficial gimmicks.
2. Fluid Readability: Use fluid typography and spacing scales that adapt seamlessly across mobile and desktop without layout shifts.
3. Purposeful Motion: Use micro-interactions (spin avatar blur, smooth tab transitions with scale(0.97) press feedback) only to indicate state and delight, never to distract.
4. Dark Monochromatic Depth: Maintain a dark `#000` base with soft white contrast (`whiteAlpha.700`) and subtle green/purple/blue accents.

## Accessibility & Inclusion
Target WCAG AA compliance, text contrast ratio ≥4.5:1 against black background, clean touch-swipe tab controls for mobile, keyboard tab navigation, and prefers-reduced-motion support.
